# 🤖 المساعد الذكي للعقارات - دليل الاستخدام

## 📱 الوصول إلى المساعد الذكي

يمكنك الوصول إلى المساعد الذكي من خلال:

1. **زر في AppBar** - أيقونة الروبوت في أعلى الصفحة الرئيسية
2. **زر عائم (FAB)** - زر ذهبي في أسفل الصفحة الرئيسية
3. **أوامر سريعة** - زر البرق في صفحة المساعد

## 🔧 الربط بـ API حقيقي (للمستقبل)

### الخطوات المطلوبة:

1. **إضافة المكتبات المطلوبة:**
```yaml
dependencies:
  http: ^1.1.0
  flutter_dotenv: ^5.1.0
```

2. **إضافة API Key:**
   - إنشاء ملف `.env` في جذر المشروع
   - إضافة: `OPENAI_API_KEY=your_key_here`

3. **تحديث `ai_service.dart`:**
   - فك تعليق دالة `_callOpenAIAPI`
   - إضافة الكود للاتصال بـ OpenAI API

### مثال الكود:
```dart
static Future<String> _callOpenAIAPI(
  String message,
  Map<String, dynamic>? context,
) async {
  final response = await http.post(
    Uri.parse('https://api.openai.com/v1/chat/completions'),
    headers: {
      'Authorization': 'Bearer $_apiKey',
      'Content-Type': 'application/json',
    },
    body: jsonEncode({
      'model': 'gpt-4',
      'messages': [
        {'role': 'system', 'content': 'أنت مساعد ذكي لإدارة العقارات...'},
        {'role': 'user', 'content': message},
      ],
    }),
  );
  
  final data = jsonDecode(response.body);
  return data['choices'][0]['message']['content'];
}
```

## 💡 نصائح للاستخدام

1. **كن محدداً**: كلما كانت رسالتك أكثر تفصيلاً، كانت الإجابة أفضل
2. **استخدم الأوامر السريعة**: للوصول السريع للمهام الشائعة
3. **اطلب التفاصيل**: المساعد يطلب التفاصيل المطلوبة تلقائياً
