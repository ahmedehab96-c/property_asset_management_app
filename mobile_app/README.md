# Mobile App (Flutter)

تطبيق الموبايل فقط (iOS / Android). لوحة الأدمن على Laravel Filament في `../backend`.

## تشغيل

```bash
cp .env.example .env
flutter pub get
flutter run
```

تأكد أن Laravel يعمل على `http://127.0.0.1:8000`.
